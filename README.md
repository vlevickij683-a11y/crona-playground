# Crona Playground

Интерактивный каталог визуальных модулей для клиентского брифа. Статический сайт без сервера данных и обязательных внешних CDN.

## Запуск

Из этой папки: `python -m http.server 8765 --bind 127.0.0.1`
Открыть http://127.0.0.1:8765/ . Для WebGPU нужен localhost или HTTPS.

## Поведение

- Кот находится в окне с самого начала, следит глазами за указателем, дышит и моргает. После загрузки страницы и готовности шрифтов проходит 2 секунды; окно автоматически разворачивается на весь экран, кот спрыгивает и открывается интерфейс. Кнопки входа нет. При reduced motion разворачивание и прыжок отключены.
- Фоны: Волны и искры, Сетка курсора, Aero Shards. Кнопки: Мягкое свечение, Объёмная кнопка. 3D-объекты: Формулы и Частицы. Дополнительно — Пространство.
- Категория и переключатель 2D/3D фильтруют каталог. У каждого модуля указано применение.
- «Сохранить вариант» сохраняет снимок настроек. Несколько вариантов одного модуля независимы.
- Избранное разделено на 2D и 3D; у каждого варианта есть комментарий, просмотр отличий, восстановление и удаление. Открытый вариант можно обновить явно либо сохранить новым.
- Бриф содержит только отличия, ID и версию модуля, комментарии и общие пожелания. Доступны копирование и TXT в UTF-8.
- Состояние хранится только в localStorage данного браузера и адреса, ключ `crona:playground:brief:v1`. Между localhost и опубликованным адресом избранное автоматически не переносится.
- Старые звёздочки `catspace:favs` переносятся один раз со стандартными настройками: прежний формат значений не сохранял.
- WebGPU-бандл Aero Shards загружается только при выборе модуля. Пока сцена готовится, показан статус. Недоступность WebGPU не мешает пользоваться каталогом и брифом.

## Проверки и сборка

`node --test brief-core.test.cjs`
`node --check app.js`
`node --check playground.js`
`node build.cjs`

Сборка копирует только необходимые файлы в dist/. Версионный catalog-v1.json фиксирует базовые настройки для интерпретации компактных брифов. При изменении значений по умолчанию нужно выпускать новую версию каталога и модулей, а не менять v1.

## Основные файлы

- app.js — исходные рендеры, параметры модулей, окно загрузки и SVG кота.
- playground.js — категории, два модуля кнопок, снимки настроек, интерфейс избранного, экспорт.
- brief-core.js — независимая логика сравнения, проверки структуры и текста брифа.
- style.css / playground.css — исходное оформление и адаптация Crona Playground.
- aero-shards.js / vendor/aero.bundle.js — существующий порт Aero Shards на WebGPU.
- .openai/hosting.json — отдельный проект хостинга Playground. Основной сайт Crona — другой проект.

Сетка курсора и Aero Shards основаны на React Bits: https://reactbits.dev/animations/cursor-grid и https://reactbits.dev/backgrounds/aero-shards . Существующие исходники и бандл сохранены.

## Примерочная сайта

Кнопка «Собрать пример сайта» открывает изолированное превью FORMA.

- Три компоновки: разделённая, центральная, журнальная.
- Три фона: градиенты, интерактивная сетка, орбитальные линии. Есть интенсивность и отключение анимации.
- Светлая/тёмная тема, общий акцент, шрифты, поверхности, скругления и отступы.
- Пять независимых кнопок: текст, стиль, цвет, размер, скругление, видимость и размещение в шапке/hero/карточке/контактах.
- Выбор кнопки или текста прямо на макете. Режим проверки взаимодействия убирает рамки выбора.
- Компьютерное превью имеет ширину 1100 px, мобильное — 390 px; в редакторе они масштабируются по доступному месту.
- Черновик и отдельные композиции сохраняются в localStorage `crona:playground:site-builder:v1`. Комментарии и изменённые поля композиций добавляются в общий TXT-бриф.
- Отмена/повтор доступны в пределах текущей сессии. Сохранённые композиции независимы от дальнейших правок черновика.
- Исходная схема закреплена в site-template-v1.json. При изменении значений по умолчанию требуется новая версия схемы.
- Во время открытой примерочной основной графический рендер каталога приостанавливается.

Файлы: builder-core.js (состояние, нормализация, контраст, экспорт), site-builder.js/css (редактор), builder-preview.html/js/css (макет в iframe).
Проверки: `node --test brief-core.test.cjs builder-core.test.cjs`.

## GitHub Pages

Public site: https://vlevickij683-a11y.github.io/crona-playground/

The workflow in .github/workflows/deploy.yml checks and builds the project, then publishes dist after every push to main. In repository Settings → Pages, the source is GitHub Actions. All local scripts, styles and iframe URLs are relative, so the site works from the repository subdirectory.

The local .openai/hosting.json belongs to the separate Sites deployment and is not required on GitHub.
